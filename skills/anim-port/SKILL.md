# anim-port (port)

Runs in the game's own chat after the user's yes for that build: exports to the target the game's profile allows, then follows the game's own version rules (backup, compile check, critics, playtest, docs). A game profile's hard rules win: a game whose arms are physically simulated takes no keyframed arm tracks.
